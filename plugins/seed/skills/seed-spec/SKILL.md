# SEED specification

Write a concise, testable specification in `memory-bank/specs/`. Cover the
objective, commands, structure, style, testing strategy, boundaries, success
criteria and open questions. Surface assumptions first. If the request spans
multiple independent capabilities, create or update `SPEC-NEXUS.md` and module
specs before planning. Do not implement from an unapproved or materially
ambiguous specification.
