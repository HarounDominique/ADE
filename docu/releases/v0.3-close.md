# ADE v0.3 — Cierre de release

**Fecha:** 2026-09-03  
**Plataforma validada:** macOS  
**Estado:** cerrada

## Alcance cerrado

La release entrega el workspace local-first definido en [SPEC-v0.3](../specs/SPEC-v0.3.md): contexto de Project, árbol y terminal PTY, proveedores agénticos, catálogo de skills, Git/GitHub y documentación viva. La unidad operativa sigue siendo `Project → Task → sesión → evidencia → ChangeSet → gates → revisión`.

La superficie del workspace mantiene una única navegación lateral etiquetada. El Explorer funciona en modo compacto alrededor del archivo activo o en modo expandido para explorar el árbol completo; al expandirlo repliega la navegación secundaria y al contraerlo restaura la rama activa.

El smoke reproducible es [`scripts/smoke-desktop-bundle.mjs`](../../scripts/smoke-desktop-bundle.mjs). El servidor OpenCode usado para la prueba se detiene al finalizar; no se persisten credenciales ni artefactos del repositorio efímero.

Después del cierre se aplicaron refinamientos de producto que describen la shell actual: selector claro/oscuro persistente, transición fluida del Explorer con soporte para reducir movimiento, hover legible en ambos temas, lateral redimensionable y dock de terminal redimensionable. La terminal ofrece tabs de sesiones PTY independientes, cada una con prompt mínimo, historial `↑`/`↓` y completado de rutas `cd` mediante `Tab`, incluyendo sugerencias ambiguas y cierre con `Esc`; cambiar de tab no mezcla transcript y cerrar uno libera sólo su proceso. `Agents` ofrece ahora un rail de sesiones y una conversación central sin inspector lateral permanente, para reservar el espacio a la interacción con el agente; la evidencia sigue en los registros de Task/runtime. La slice v0.4 añadió el editor interno para ficheros de texto, con guardado, descarte y apertura externa explícita. El Explorer también incorpora búsqueda file-first con rutas contextuales, índice reutilizable, debounce y spinner transitorio.

Estas mejoras son mantenimiento UX y no reabren la release. La baseline actual es `npm test` con 104 tests TypeScript y `cargo test` con 18 tests Rust; la tabla anterior conserva la evidencia exacta del corte de cierre del 2026-09-03. El panel operativo `Git workspace` queda restringido a `Version control`; la topbar conserva únicamente los selectores globales de Project y branch. El bundle `.app` se genera y se ha arrancado manualmente en macOS; el smoke gráfico automatizado sigue pendiente.

## Límites explícitos

No forman parte de 0.3: editor IDE completo, `.dmg`, cloud, colaboración realtime, retrieval semántico, checkpoints automáticos, commits autónomos y sandbox OS-level. La conversación del proveedor se representa mediante sesiones y evidencia acotada, no mediante una transcripción completa de prompts y tokens.

## Siguiente corte

La siguiente iteración debe abrirse en una spec nueva y no reabrir esta release. La slice v0.4 está definida en [SPEC-file-workspace](../specs/SPEC-file-workspace.md); cualquier ampliación que cambie los contratos de Project, Task, sesión, Git o documentación debe actualizar primero el Nexus y las specs dependientes.
